## How I Approach Problems

I start by identifying what can go wrong in the process.

Then I:

1. Define the quality requirement
2. Inspect the data or workflow
3. Identify errors or bottlenecks
4. Apply a consistent method
5. Validate the output
6. Measure the result

The objective is not simply to process more data.

The objective is to produce **accurate, consistent, and usable results that can be trusted downstream.**
