# Project 01 — AI Data Annotation & Quality Control

## Project Overview

This project demonstrates a structured approach to annotating AI training data while maintaining consistency and quality.

The workflow focuses on three areas:

- Accurate labeling
- Handling ambiguous examples
- Quality control before submission

## Problem

High-volume annotation can create inconsistent labels when similar items are interpreted differently by different annotators.

Small inconsistencies can reduce the quality of downstream training data.

## Objective

Build a simple annotation workflow that makes labeling decisions consistent, reviewable, and easy to audit.

## Workflow

Raw Data → Annotation → Ambiguity Review → Quality Check → Final Dataset
